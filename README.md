# Vietnam — The Shopping Edit

A responsive visual shopping catalogue for Vietnam with recipient/category filters, search, illustrative photos, wishlist, quantity-based cart, INR estimate ranges and browser-local saving.

## Publish
This repository is configured for GitHub Pages manually:
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. Wait for the deployment. The site URL will be https://junaidfazlani04.github.io/Vietnam-shopping/

## Notes
- Cart and wishlist are stored in the visitor's browser.
- Photos are representative Unsplash images, not verified exact products.
- Prices are broad INR planning estimates, not live quotes.
- Check quality, sizing, authenticity, food labelling and Indian customs/import rules before buying.
